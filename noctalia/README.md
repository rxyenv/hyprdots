# Obsidian

A dark Noctalia v5 palette with a `#0b0c0f` background and `#a0a8b8` accents.
Raised surfaces use cool charcoal; terminal ANSI colors use muted hues to keep
errors, diffs, and syntax distinguishable.

Copy `palettes/Obsidian.json` to `~/.config/noctalia/palettes/Obsidian.json`.
In your Noctalia configuration, merge these settings into the existing `[theme]`
section:

```toml
[theme]
source = "custom"
custom_palette = "Obsidian"
```

Only a dark variant is supplied. Noctalia also uses it in light mode.

Format and configuration reference:
<https://docs.noctalia.dev/noctalia/theming/palette/>
